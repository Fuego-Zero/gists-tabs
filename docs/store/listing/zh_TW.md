芸箋 · Gists Tabs 把 Chrome 的新分頁變成一塊你自己排布的工作台。

• 多個頁面，把工作、學習和其他事情分開
• 書籤小工具帶網站圖示，依欄位分組
• 把小工具拖到另一欄，再儲存
• 世界時鐘，同時看你在意的城市
• 從工具列把目前的分頁存進書籤組
• 淺色 / 深色主題
• 介面語言：中文和 English
• 資料預設只在這台瀏覽器裡，除非你打開同步
• 可選：用你自己的 Token，同步到私人 GitHub Gist
• 畫布可以匯出、匯入 JSON

權限
• storage：把工作台保存在這台裝置
• tabs 和 activeTab：讀取目前的分頁，方便一鍵收藏
• alarms：打開雲端同步之後，依排程重試同步

Token 只存在擴充功能的本機儲存裡，只用來讀寫你 GitHub 帳號下的 Gist。經典個人存取權杖需要 gist 權限；細粒度權杖需要對 Gist 的讀寫權限。資料不會送到擴充功能作者的伺服器。
