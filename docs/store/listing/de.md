Gists Tabs macht den neuen Tab in Chrome zu einem Arbeitsplatz, den du selbst anordnest.

• Mehrere Seiten, damit Arbeit, Lernen und der Rest getrennt bleiben
• Lesezeichen-Widgets mit Website-Icons, in Spalten gruppiert
• Ziehe ein Widget in eine andere Spalte und speichere dann
• Eine Weltuhr für die Städte, die dich interessieren
• Speichere den aktuellen Tab über die Symbolleiste in einer Gruppe
• Importiere Chrome-Lesezeichenordner. Jeder Ordner wird eine Gruppe. Die Lesezeichen-Berechtigung wird erst beim Importieren verlangt
• Helles und dunkles Thema
• Oberfläche auf English, 简体中文, 繁體中文, 日本語, 한국어, Español, Português, Deutsch, Français und Русский. Sie folgt dem Browser, bis du eine Sprache wählst
• Die Daten bleiben in diesem Browser, bis du die Synchronisierung einschaltest
• Optional: mit deinem eigenen Token in ein privates GitHub Gist synchronisieren
• Die Fläche als JSON exportieren und importieren

Berechtigungen
• storage — den Arbeitsplatz auf diesem Gerät speichern
• tabs und activeTab — den aktuellen Tab lesen, damit du ihn mit einem Klick sichern kannst
• alarms — die Synchronisierung erneut versuchen, nachdem du die Cloud einschaltest
• bookmarks — optional, nur beim Importieren von Chrome-Lesezeichen

Das Token liegt nur im lokalen Speicher der Erweiterung. Es liest und schreibt Gists deines GitHub-Kontos. Ein klassisches persönliches Token braucht den Bereich gist. Ein fein abgestuftes Token braucht Lese- und Schreibzugriff auf Gists. Es wird nichts an einen Server der Erweiterungsautoren gesendet.
