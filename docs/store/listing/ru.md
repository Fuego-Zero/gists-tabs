Gists Tabs превращает новую вкладку Chrome в рабочее место, которое вы раскладываете сами.

• Несколько страниц, чтобы разделить работу, учёбу и остальное
• Виджеты закладок с иконками сайтов, собранные в колонки
• Перетащите виджет в другую колонку и сохраните
• Мировые часы для нужных городов
• Сохраните текущую вкладку с панели инструментов в группу закладок
• Светлая и тёмная тема
• Язык интерфейса: English и 中文
• Данные остаются в этом браузере, пока вы не включите синхронизацию
• По желанию — синхронизация в закрытый GitHub Gist вашим токеном
• Холст можно экспортировать и импортировать как JSON

Разрешения
• storage — хранить рабочее место на этом устройстве
• tabs и activeTab — читать текущую вкладку, чтобы сохранить её в один клик
• alarms — повторять синхронизацию по расписанию после включения облака

Токен хранится только в локальном хранилище расширения. Он нужен, чтобы читать и записывать Gist вашей учётной записи GitHub. Классическому токену нужна область gist. Токену с тонкой настройкой нужны чтение и запись Gist. На сервер автора расширения ничего не отправляется.

Исходный код: https://github.com/Fuego-Zero/gists-tabs
