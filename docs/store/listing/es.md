Gists Tabs convierte la nueva pestaña de Chrome en un espacio que organizas tú.

• Varias páginas, para separar trabajo, estudio y lo demás
• Widgets de marcadores con iconos, agrupados en columnas
• Arrastra un widget a otra columna y luego guarda
• Un reloj mundial para las ciudades que te importan
• Guarda la pestaña actual desde la barra de herramientas
• Importa carpetas de marcadores de Chrome. Cada carpeta se convierte en un grupo. El permiso de marcadores solo se pide al importar
• Tema claro y oscuro
• Interfaz en English, 简体中文, 繁體中文, 日本語, 한국어, Español, Português, Deutsch, Français y Русский. Sigue al navegador hasta que elijas
• Los datos se quedan en este navegador, salvo que actives la sincronización
• Opción de sincronizar con un Gist privado de GitHub, con tu propio token
• Exporta e importa el lienzo como JSON

Permisos
• storage — guardar el espacio de trabajo en este dispositivo
• tabs y activeTab — leer la pestaña actual para guardarla en un clic
• alarms — reintentar la sincronización cuando activas la nube
• bookmarks — opcional, solo cuando importas carpetas de Chrome

El token solo se guarda en el almacenamiento local de la extensión. Sirve para leer y escribir Gists de tu cuenta de GitHub. Un token clásico necesita el alcance gist. Un token detallado necesita permiso de lectura y escritura sobre Gists. No se envía nada al servidor del autor de la extensión.
