Gists Tabs は、Chrome の新しいタブを自分で並べる作業台にします。

• ページを分けて、仕事と学習とその他を置ける
• サイトアイコン付きのブックマークを列にまとめる
• ウィジェットを別の列へドラッグして保存
• 気になる都市の世界時計
• ツールバーから、表示中のタブをブックマークグループへ保存
• Chrome のブックマークフォルダを読み込める。フォルダごとにグループになる。ブックマーク権限は読み込むときだけ求める
• ライト / ダークテーマ
• 画面は English、简体中文、繁體中文、日本語、한국어、Español、Português、Deutsch、Français、Русский。選ぶまではブラウザに従う
• 同期をオンにするまで、データはこのブラウザの中だけ
• 自分の Token で、非公開の GitHub Gist に同期できる
• キャンバスは JSON で書き出し、読み込みできる

権限
• storage — 作業台をこの端末に保存する
• tabs と activeTab — 表示中のタブを読み、ワンクリックで保存する
• alarms — クラウド同期をオンにしたあと、再試行をスケジュールする
• bookmarks — 任意。Chrome のブックマークを読み込むときだけ

Token は拡張機能のローカルストレージだけに保存され、あなたの GitHub アカウントの Gist を読み書きするためだけに使います。クラシックな個人アクセス Token には gist スコープが必要です。Fine-grained Token には Gist の読み書き権限が必要です。拡張機能の作者のサーバーには送られません。
