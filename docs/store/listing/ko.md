Gists Tabs는 Chrome 새 탭을 직접 배치하는 작업 공간으로 바꿉니다.

• 페이지를 나눠 일, 공부, 그 밖의 것을 따로 둡니다
• 사이트 아이콘이 있는 북마크를 열로 모읍니다
• 위젯을 다른 열로 끌어다 놓은 뒤 저장합니다
• 보고 싶은 도시의 세계 시계
• 도구 모음에서 현재 탭을 북마크 그룹에 저장합니다
• 라이트 / 다크 테마
• 화면 언어는 English와 중문입니다
• 동기화를 켜기 전에는 데이터가 이 브라우저 안에만 있습니다
• 원하는 경우 자신의 Token으로 비공개 GitHub Gist에 동기화합니다
• 캔버스는 JSON으로 내보내고 가져올 수 있습니다

권한
• storage — 작업 공간을 이 기기에 저장합니다
• tabs와 activeTab — 현재 탭을 읽어 한 번에 저장합니다
• alarms — 클라우드 동기화를 켠 뒤 재시도를 예약합니다

Token은 확장 프로그램의 로컬 저장소에만 있으며, 내 GitHub 계정의 Gist를 읽고 쓰는 데만 쓰입니다. 클래식 개인용 액세스 토큰에는 gist 범위가 필요합니다. 세분화된 토큰에는 Gist 읽기 및 쓰기 권한이 필요합니다. 확장 프로그램 작성자의 서버로는 전송되지 않습니다.
